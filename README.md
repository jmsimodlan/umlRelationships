# UML Relationships in Python

## About This Project

This repository contains my sample Python codes about the six UML relationships we learned in our lesson. Each file shows a simple example of how these relationships work in Object-Oriented Programming (OOP).

## UML Relationships

### 1. Inheritance (Is-a)
This is when a child class gets the attributes and methods of a parent class. For example, a Dog is an Animal.

File: inheritance.py

### 2. Composition (Strong Has-a)
This is when a class creates and owns another object. For example, a Car has an Engine that is created inside the Car class.

File: composition.py

### 3. Aggregation (Weak Has-a)
This is when a class uses objects that can still exist independently. For example, a Team has Players, but the Players can exist even without the Team.

File: aggregation.py

### 4. Association (Knows-a)
This is when two independent objects are connected and know about each other. For example, a Student knows their Teacher.

File: association.py

### 5. Dependency (Uses-a)
This is when a class temporarily uses another class to do something. For example, a Report uses a Printer to print a message.

File: dependency.py

### 6. Realization / Implementation (Implements)
This is when a class follows the requirements of an abstract class or interface. In Python, we can use the abc module for this.

File: realization.py

Through these examples, I learned how different classes can be connected and how UML relationships are used in Python.
